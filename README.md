# 🔌 电路原理智能解题系统

> 基于 Claude Code 的大学电路原理课程智能解题助手，拍照即可获得完整解题过程。

---

## 📖 项目简介

这是一个为大学《电路原理》课程设计的 AI 解题工具。它作为一个 Claude Code Skill（`/circuit` 命令）运行，能够：

1. **识别电路图** — 通过拍照或上传图片，AI 自动识别电路中的所有元件和连接关系
2. **分析题型** — 智能匹配最适合的解题方法（节点电压法、叠加定理、戴维南定理等）
3. **输出完整解题过程** — 不仅给出答案，还展示每一步的推导过程、依据的定理和公式
4. **验证答案** — 用第二种方法验算，确保答案正确

### 适用场景

- 📚 课后作业遇到不会做的题
- 📝 考前复习需要大量刷题
- 🤔 想理解某种解题方法的具体步骤
- ✅ 做完题想验证答案是否正确

## 🎯 核心特性

### 知识库覆盖

基于邱关源《电路》（第6版）教材，覆盖电路原理课程全部核心内容：

| 模块 | 章节 | 核心知识点 |
|------|------|-----------|
| **基础电路分析** | 第1-5章 | 欧姆定律、KCL/KVL、等效变换、节点电压法、网孔电流法、叠加定理、戴维南定理、运放电路 |
| **暂态分析** | 第6-7章 | 电感电容特性、换路定则、三要素法、RL/RC/RLC一阶二阶电路时域分析 |
| **正弦稳态分析** | 第8-13章 | 相量法、阻抗导纳、正弦稳态电路分析、功率分析与功率因数校正、谐振、互感与变压器、三相电路 |
| **高级分析方法** | 第14-18章 | 复频域分析（拉普拉斯变换）、矩阵形式、二端口网络、非线性电路 |

### 支持的题型

系统内置 9 种题型模板，覆盖课程最常考的知识点：

```
✅ 欧姆定律与电阻电路        ✅ 叠加定理
✅ 基尔霍夫定律（KCL/KVL）    ✅ 戴维南/诺顿定理
✅ 节点电压法                ✅ RL/RC/RLC暂态分析
✅ 网孔电流法                ✅ 正弦稳态与相量分析
                            ✅ 功率分析与功率因数校正
```

### 输出格式

每道题的标准输出包含 5 个部分：

```
📋 题目分析  — 识别题型、难度、关键元件
🔧 解题方法  — 选择的方法及理由
📝 解题步骤  — 逐步推导（含公式、代入、计算）
✅ 最终答案  — 明确标注答案 + 验算
💡 知识回顾  — 涉及的知识点、易错点、类似题型特征
```

## 🚀 快速开始

### 前置条件

- 已安装 [Claude Code](https://docs.anthropic.com/en/docs/claude-code)
- Claude Code 已连接到你的项目目录

### 使用方法

1. **克隆仓库**
   ```bash
   git clone https://github.com/Canger-cye/circuit-solver.git
   cd circuit-solver
   ```

2. **将 `.claude/commands/circuit.md` 复制到你的项目中**
   ```bash
   mkdir -p .claude/commands
   cp circuit-solver/.claude/commands/circuit.md .claude/commands/
   ```

3. **启动 Claude Code，输入 `/circuit`**
   ```
   > /circuit
   > [发送电路图照片]
   ```

### 示例交互

```
用户: /circuit
用户: [发送一张电路图照片]

AI: ## 📋 题目分析
    **题型**: 节点电压法
    **难度**: medium
    **关键元件**: 42V电压源、2A电流源、R(待求)、4Ω、20Ω、10Ω、50Ω、5Ω
    
    ## 🔧 解题方法
    **使用方法**: 节点电压法 + 利用 Uab=0 条件简化
    ...
    
    ## ✅ 最终答案
    **答案**: **R = 15Ω**
```

## 🔧 技术实现

### 知识库架构

```
输入题目 → 图片识别/文字解析 → 题型匹配 → 加载对应知识 → 逐步解题 → 验证答案
                ↓                    ↓              ↓
          电路图OCR识别        关键词匹配模板    读取教材对应章节
```

### 关键设计

1. **分层知识库**：教材笔记（详细讲解）→ 知识点速查（公式汇总）→ 题型模板（解题步骤）
2. **智能题型匹配**：根据题目关键词自动选择最适合的解题模板
3. **双重验证**：尽量用两种方法验算答案，提高准确性
4. **结构化输出**：标准化的解题格式，方便学习和复习
