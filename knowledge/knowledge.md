## 模块一：基础电路分析

### 1.1 电路基本概念

- **电流 i(t)**：单位时间内通过导体横截面的电荷量，i = dq/dt
- **电压 v(t)**：单位电荷的电位能差，v = dw/dq
- **关联参考方向**：电流从电压 "+" 端流入，此时 p = vi 为元件吸收功率
- **非关联参考方向**：电流从电压 "-" 端流入，此时 p = vi 为元件发出功率
- **功率守恒**：任一集中参数电路中，所有元件吸收功率之代数和为零：∑p = 0

### 1.2 电路元件

| 元件 | V-I关系 | 特点 |
|------|---------|------|
| 电阻 R | v = Ri | 消耗能量，记忆元件 |
| 电感 L | v = L·di/dt | 储存磁场能 W = ½Li² |
| 电容 C | i = C·dv/dt | 储存电场能 W = ½Cv² |
| 独立电压源 | v = v_s(t) | 输出电压与电流无关 |
| 独立电流源 | i = i_s(t) | 输出电流与电压无关 |
| 受控电压源 | v = f(其他变量) | 电压由电路中某处变量控制 |
| 受控电流源 | i = f(其他变量) | 电流由电路中某处变量控制 |

**受控源类型**：
- VCVS（电压控制电压源）：v = μv₁
- VCCS（电压控制电流源）：i = gm·v₁
- CCVS（电流控制电压源）：v = r·i₁
- CCCS（电流控制电流源）：i = β·i₁

### 1.3 欧姆定律

**基本形式**：v = Ri（关联参考方向）

**注意事项**：
- 必须先确定参考方向，再列写方程
- 电阻始终为正值（正电阻）
- 功率 p = i²R = v²/R = vi

### 1.4 基尔霍夫定律

#### 基尔霍夫电流定律（KCL）
**内容**：任一集中参数电路中，任一时刻，流出（或流入）任一节点的各支路电流代数和为零。

$$\sum_{k=1}^{n} i_k = 0$$

**推广**：KCL 适用于任意闭合面（广义节点）

**使用要点**：
- 先假设各支路电流参考方向
- 流出节点取正（或流入取正），保持一致
- 独立方程数 = 节点数 - 1

#### 基尔霍夫电压定律（KVL）
**内容**：任一集中参数电路中，任一时刻，沿任一回路各支路电压代数和为零。

$$\sum_{k=1}^{n} v_k = 0$$

**推广**：KVL 适用于任意闭合路径（广义回路）

**使用要点**：
- 沿回路方向，电压降取正（或升取正），保持一致
- 独立方程数 = 基本回路数 = 支路数 - (节点数 - 1)

### 1.5 等效变换

#### 电阻串联与并联
- **串联**：R_eq = R₁ + R₂ + ... + Rₙ，电流相同，电压分配
- **并联**：1/R_eq = 1/R₁ + 1/R₂ + ... + 1/Rₙ，电压相同，电流分配
- **两电阻并联**：R_eq = R₁R₂ / (R₁ + R₂)

#### 电压源与电流源互换
- 电压源 v_s 串联 R_s ⟺ 电流源 i_s = v_s/R_s 并联 R_s
- 条件：内阻 R_s 相同

#### Y-Δ 变换（T-π 变换）
**Y → Δ**：
$$R_{12} = \frac{R_1R_2 + R_2R_3 + R_3R_1}{R_3}$$

**Δ → Y**：
$$R_1 = \frac{R_{12}R_{13}}{R_{12} + R_{23} + R_{13}}$$

### 1.6 节点电压法

**步骤**：
1. 选参考节点（接地），标记其余节点编号
2. 对每个独立节点列写 KCL 方程（用节点电压表示支路电流）
3. 求解节点电压
4. 由节点电压求各支路电流/电压

**自导与互导**：
- 自导 G_ii = 连接节点 i 的所有电导之和（恒正）
- 互导 G_ij = 节点 i 与 j 之间电导之和（恒负，不含受控源时）

**标准形式**：
$$G_{11}V_1 + G_{12}V_2 + ... = I_{s1}$$
$$G_{21}V_1 + G_{22}V_2 + ... = I_{s2}$$

**含受控源时**：将受控源当独立源处理，最后将控制量用节点电压表示，移到方程左边。

### 1.7 网孔电流法

**步骤**：
1. 选网孔，假设网孔电流方向（通常取顺时针）
2. 对每个网孔列写 KVL 方程（用网孔电流表示支路电压）
3. 求解网孔电流
4. 由网孔电流求各支路电流/电压

**自阻与互阻**：
- 自阻 R_ii = 网孔 i 中所有电阻之和（恒正）
- 互阻 R_ij = 网孔 i 与 j 公共支路电阻（同向取正，反向取负）

**标准形式**：
$$R_{11}I_1 + R_{12}I_2 = V_{s1}$$
$$R_{21}I_1 + R_{22}I_2 = V_{s2}$$

### 1.8 叠加定理

**内容**：线性电路中，任一支路的响应（电压或电流）等于各独立源单独作用时在该支路产生的响应的代数和。

**使用步骤**：
1. 保留一个独立源，其余电压源短路、电流源开路
2. 分别计算各独立源单独作用时的响应
3. 代数叠加（注意参考方向）

**注意事项**：
- 仅适用于线性电路
- 功率不满足叠加（因为 p ∝ i² 或 p ∝ v²）
- 受控源不参与单独作用，始终保留在电路中

### 1.9 戴维南定理与诺顿定理

#### 戴维南定理
**内容**：任何线性含源二端网络，对外部电路而言，可用一个电压源 v_oc 串联一个电阻 R_eq 等效替代。

- **v_oc**：端口开路电压
- **R_eq**：将网络内所有独立源置零后，从端口看进去的等效电阻

**求 R_eq 的方法**：
1. **方法一**：独立源置零（电压源短路、电流源开路），直接计算等效电阻
2. **方法二**：R_eq = v_oc / i_sc（开路电压除以短路电流）
3. **方法三**：外加电源法 — 在端口加电压源 v，求电流 i，则 R_eq = v/i

#### 诺顿定理
**内容**：任何线性含源二端网络，对外部电路而言，可用一个电流源 i_sc 并联一个电阻 R_eq 等效替代。

- **i_sc**：端口短路电流
- **R_eq**：同戴维南等效电阻

**转换关系**：v_oc = i_sc · R_eq

### 1.10 最大功率传输定理

**内容**：当负载电阻 R_L 等于戴维南等效电阻 R_eq 时，负载获得最大功率。

$$P_{max} = \frac{v_{oc}^2}{4R_{eq}}$$

**条件**：R_L = R_eq（共轭匹配时用于交流电路：Z_L = Z_eq*）

## 模块二：动态元件电路

### 2.1 电感与电容的特性

#### 电感 L
- V-I：v = L·di/dt
- 电流不能突变：i(t₀⁺) = i(t₀⁻)
- 储能：W = ½Li²
- 直流稳态时：电感短路（v = 0）
- 交流稳态时：感抗 X_L = ωL，电压超前电流 90°

#### 电容 C
- V-I：i = C·dv/dt
- 电压不能突变：v(t₀⁺) = v(t₀⁻)
- 储能：W = ½Cv²
- 直流稳态时：电容开路（i = 0）
- 交流稳态时：容抗 X_C = 1/(ωC)，电流超前电压 90°

### 2.2 换路定则

$$v_C(t_0^+) = v_C(t_0^-)$$
$$i_L(t_0^+) = i_L(t_0^-)$$

**注意**：电容电压和电感电流不能突变，但其导数可以突变。

### 2.3 一阶电路暂态分析（三要素法）

**适用范围**：一阶线性电路（RC 或 RL 电路）

**三要素**：
1. **初始值 f(0⁺)**：由换路定则和 t=0⁺ 等效电路求得
2. **稳态值 f(∞)**：t → ∞ 时的稳态值（电容开路、电感短路）
3. **时间常数 τ**：
   - RC 电路：τ = RC
   - RL 电路：τ = L/R
   - R 为从储能元件两端看进去的戴维南等效电阻

**求解公式**：
$$f(t) = f(\infty) + [f(0^+) - f(\infty)] \cdot e^{-t/\tau}$$

**三要素法步骤**：
1. 画 t = 0⁻ 等效电路，求初始状态 v_C(0⁻) 或 i_L(0⁻)
2. 由换路定则得 v_C(0⁺) 或 i_L(0⁺)
3. 画 t = 0⁺ 等效电路（电容用电压源替代，电感用电流源替代），求待求量初始值
4. 画 t → ∞ 等效电路（电容开路、电感短路），求稳态值
5. 求时间常数 τ = R_eq·C 或 τ = L/R_eq
6. 代入公式

### 2.4 二阶电路暂态分析

**RLC 串联电路微分方程**：
$$LC\frac{d^2v_C}{dt^2} + RC\frac{dv_C}{dt} + v_C = v_s$$

**特征方程**：
$$s^2 + \frac{R}{L}s + \frac{1}{LC} = 0$$

**特征根**：
$$s_{1,2} = -\frac{R}{2L} \pm \sqrt{\left(\frac{R}{2L}\right)^2 - \frac{1}{LC}}$$

**三种情况**：
| 条件 | 根的性质 | 响应类型 |
|------|---------|---------|
| R > 2√(L/C) | 两个不等负实根 | 过阻尼（非振荡） |
| R = 2√(L/C) | 两个相等负实根 | 临界阻尼（非振荡） |
| R < 2√(L/C) | 共轭复根 | 欠阻尼（振荡衰减） |

### 2.5 复频域分析（拉普拉斯变换法）

**基本变换对**：
| 时域 f(t) | 复频域 F(s) |
|-----------|-------------|
| δ(t) | 1 |
| u(t) | 1/s |
| e^(-at)u(t) | 1/(s+a) |
| cos(ωt)u(t) | s/(s²+ω²) |
| sin(ωt)u(t) | ω/(s²+ω²) |
| df/dt | sF(s) - f(0⁻) |
| ∫f(t)dt | F(s)/s + f⁻¹(0)/s |

**s域元件模型**：
- 电阻：V(s) = RI(s)
- 电感：V(s) = sLI(s) - Li(0⁻)（串联模型）或 I(s) = V(s)/(sL) + i(0⁻)/s（并联模型）
- 电容：V(s) = I(s)/(sC) + v(0⁻)/s（串联模型）或 I(s) = sCV(s) - Cv(0⁻)（并联模型）

**s域分析步骤**：
1. 画 s 域等效电路（含初始条件的附加源）
2. 列写 s 域方程（KCL/KVL）
3. 求解得到象函数 F(s)
4. 部分分式展开
5. 反变换得时域解

## 模块三：交流电路分析

### 3.1 正弦量与相量

**正弦量三要素**：幅值 A_m、角频率 ω、初相位 φ
$$x(t) = A_m \cos(\omega t + \phi)$$

**有效值**：X = A_m / √2

**相量表示**：
- 幅值相量：Ẋ_m = A_m ∠φ
- 有效值相量：Ẋ = X ∠φ（更常用）

**相量的运算**：
- 同频率正弦量的加减 → 相量的加减（复数运算）
- 时域微分 → 相量乘以 jω
- 时域积分 → 相量除以 jω

### 3.2 阻抗与导纳

**阻抗**：
$$Z = R + jX = |Z|∠\theta_z$$
- R：电阻（实部）
- X：电抗（虚部），感抗为正，容抗为负
- |Z| = √(R² + X²)：阻抗模
- θ_z = arctan(X/R)：阻抗角

**导纳**：
$$Y = G + jB = \frac{1}{Z} = |Y|∠\theta_y$$
- G：电导（实部）
- B：电纳（虚部）

**元件阻抗**：
| 元件 | 阻抗 Z | 导纳 Y |
|------|--------|--------|
| 电阻 R | R | 1/R |
| 电感 L | jωL | 1/(jωL) = -j/(ωL) |
| 电容 C | 1/(jωC) = -j/(ωC) | jωC |

**串并联**：
- 串联：Z = Z₁ + Z₂ + ... + Zₙ
- 并联：Y = Y₁ + Y₂ + ... + Yₙ 或 1/Z = 1/Z₁ + 1/Z₂ + ...

### 3.3 正弦稳态电路分析

**分析方法**：将时域问题转化为复数代数方程

**步骤**：
1. 将正弦量用相量表示
2. 将元件用阻抗（或导纳）表示
3. 列写相量形式的 KCL/KVL 方程
4. 求解相量
5. 将相量结果转换回时域

**节点电压法（相量形式）**：
$$Y_{11}\dot{V}_1 + Y_{12}\dot{V}_2 + ... = \dot{I}_{s1}$$

**网孔电流法（相量形式）**：
$$Z_{11}\dot{I}_1 + Z_{12}\dot{I}_2 + ... = \dot{V}_{s1}$$

### 3.4 正弦稳态功率

#### 瞬时功率
$$p(t) = v(t) \cdot i(t) = V_m I_m \cos(\omega t + \theta_v) \cos(\omega t + \theta_i)$$

#### 有功功率（平均功率）
$$P = VI\cos(\theta_v - \theta_i) = VI\cos\phi$$
- 单位：W（瓦）
- φ = θ_v - θ_i 为功率因数角
- cosφ 为功率因数

#### 无功功率
$$Q = VI\sin\phi$$
- 单位：var（乏）
- 感性负载 Q > 0，容性负载 Q < 0

#### 视在功率
$$S = VI$$
- 单位：VA（伏安）

#### 功率三角形
$$S = P + jQ = VI^* = |S|∠\phi$$
$$|S| = \sqrt{P^2 + Q^2}$$
$$\cos\phi = P/S$$

#### 复功率
$$\tilde{S} = \dot{V}\dot{I}^* = P + jQ$$

#### 最大功率传输（交流）
当负载阻抗 Z_L = Z_eq*（共轭匹配）时，负载获得最大功率：
$$P_{max} = \frac{|V_{oc}|^2}{8R_{eq}}$$

### 3.5 功率因数校正

**问题**：感性负载使功率因数偏低，导致线路损耗增大、设备利用率降低

**方法**：并联电容器，使总功率因数提高到目标值

**计算**：
$$C = \frac{P(\tan\phi_1 - \tan\phi_2)}{\omega V^2}$$
- φ₁：校正前功率因数角
- φ₂：校正后功率因数角
- P：有功功率
- V：端口电压有效值

### 3.6 谐振

#### 串联谐振（RLC串联）
**条件**：Im(Z) = 0 → ωL = 1/(ωC)
$$\omega_0 = \frac{1}{\sqrt{LC}}, \quad f_0 = \frac{1}{2\pi\sqrt{LC}}$$

**特点**：
- 阻抗最小：Z = R（纯电阻）
- 电流最大：I = V/R
- 电感电压 = 电容电压 = QV（Q 为品质因数）
- 品质因数：Q = ω₀L/R = 1/(ω₀CR)

#### 并联谐振（RLC并联）
**条件**：Im(Y) = 0
$$\omega_0 \approx \frac{1}{\sqrt{LC}}$$

**特点**：
- 导纳最小（阻抗最大）
- 总电流最小
- 支路电流可能远大于总电流（Q 倍）

### 3.7 互感与变压器

#### 互感
**定义**：两个耦合线圈，一个线圈中的电流变化在另一个线圈中产生感应电压

$$v_1 = L_1\frac{di_1}{dt} + M\frac{di_2}{dt}$$
$$v_2 = M\frac{di_1}{dt} + L_2\frac{di_2}{dt}$$

**互感系数**：M = k√(L₁L₂)，k 为耦合系数（0 ≤ k ≤ 1）

**同名端**：电流从同名端流入时，互感电压与自感电压同号

#### 去耦等效
**串联**：
- 顺串：L = L₁ + L₂ + 2M
- 反串：L = L₁ + L₂ - 2M

**并联**：
- 同侧并联：L = (L₁L₂ - M²)/(L₁ + L₂ - 2M)
- 反侧并联：L = (L₁L₂ - M²)/(L₁ + L₂ + 2M)

#### 理想变压器
**条件**：k = 1，L₁, L₂ → ∞，无损耗

**关系**：
$$\frac{v_1}{v_2} = \frac{n_1}{n_2} = n$$
$$\frac{i_1}{i_2} = -\frac{n_2}{n_1} = -\frac{1}{n}$$

**阻抗变换**：从原边看进去的等效阻抗 Z_in = n²Z_L

### 3.8 三相电路

**对称三相电源**：
$$v_A = V_m\cos(\omega t)$$
$$v_B = V_m\cos(\omega t - 120°)$$
$$v_C = V_m\cos(\omega t + 120°)$$

**Y 形连接**：
- 线电压 = √3 × 相电压，超前相电压 30°
- 线电流 = 相电流

**Δ 形连接**：
- 线电压 = 相电压
- 线电流 = √3 × 相电流，滞后相电流 30°

**三相功率**：
$$P = \sqrt{3}V_L I_L \cos\phi$$
$$Q = \sqrt{3}V_L I_L \sin\phi$$
$$S = \sqrt{3}V_L I_L$$

## 附录：常用公式速查

### 三角函数
- sin(A ± B) = sinA·cosB ± cosA·sinB
- cos(A ± B) = cosA·cosB ∓ sinA·sinB
- sin²A + cos²A = 1
- 2sinA·cosB = sin(A+B) + sin(A-B)

### 复数运算
- (a+jb)(c+jd) = (ac-bd) + j(ad+bc)
- 1/j = -j
- j² = -1
- 共轭复数：(a+jb)* = a-jb
- 模：|a+jb| = √(a²+b²)
- 辐角：∠(a+jb) = arctan(b/a)

### 微积分
- d(e^(at))/dt = a·e^(at)
- ∫e^(at)dt = e^(at)/a + C
- d(cos(ωt))/dt = -ω·sin(ωt)
- d(sin(ωt))/dt = ω·cos(ωt)
